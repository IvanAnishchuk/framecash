# Probes

Throwaway scripts that answer one feasibility question each. One directory per question,
named after it: `f01-eip2537-on-devnet/`, `f02-staked-validation-budget/`, and so on.

Each directory's README states:
- what it checks, and which `research/feasibility/` file it answers;
- how to run it, including any env vars (keys live in a gitignored `.env`);
- the result, with the date and the client or tool versions.

Copy the result into the feasibility file as well. Keys used here are throwaway devnet
or testnet keys.
